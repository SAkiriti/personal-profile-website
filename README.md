# Personal Profile Website

A two-page profile site built with semantic HTML and CSS, with no frameworks or JavaScript.

## Tech stack

HTML · CSS

## Features

- Semantic markup using `header`, `nav`, `main`, `section` and `footer`
- Relative navigation links between the Home and Contact pages
- Three content cards on the Home page: an introduction, a skills list and a data table
- A card layout built with Flexbox and `flex-wrap`, so cards reflow onto the next line as the window narrows, with no media queries needed
- An accessible contact form where every `label` is bound to its input with `for` and `id`

## Running it

Open `index.html` in a browser, or serve the folder with Live Server.

## Structure

```
index.html     Home page: about, skills and weekly schedule
contact.html   Contact form
styles.css     Shared stylesheet for both pages

```
